# Contributing

No bot PRs or automated AI dumps. If a PR was opened by a bot or blindly generated without you checking it, it will be closed.

Using AI to help write code is okay, as long as you actually know what every line does, tested it yourself, and can answer questions about it in review. If it's obvious you don't understand your own PR or you're pasting AI replies to review comments, we'll close it.

A few things before opening a PR:
- Keep PRs small and focused on one thing. Don't mix random cleanup with a bug fix.
- Base server behavior on client code or game data, not guesswork.
- State clearly what you tested in-game vs what only passed unit tests or compiled. Don't claim something works in-game if you didn't actually run it.
- Note what you changed, why, and anything still untested.
